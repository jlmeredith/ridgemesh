# Radio and placement implementation evidence — 2026-09-12

Model `ridgemesh-rf-2.0` replaces the symmetric-power heuristic with directed budgets, physical-length vegetation integration, terrain-only obstruction, first Fresnel clearance and a dominant single knife edge. Source terrain and ground-relative antenna heights are separate. Unknown terrain/configuration returns unknown; Totem is unknown by default. M1/V4 parameters are declared editable engineering assumptions, never field-certified hardware facts. The Heltec default is 22 dBm; the old unconditional 28 dBm assumption has been removed.

Primary references checked: [ITU-R P.526](https://www.itu.int/rec/R-REC-P.526/en), [Meshtastic roles](https://meshtastic.org/docs/configuration/radio/device/), [Heltec V4 variants](https://heltec.org/project/wifi-lora-32-v4/). Meshtastic CLIENT can forward; CLIENT_MUTE cannot. Model `client` obeys the forwarding scenario switch, `mute` never forwards, `router` forwards. Model hops count RF edges including final receiver; this explicit planning convention is not claimed to reproduce every firmware hop field. Channels and modem/frequency must match; no cross-system bridges exist. Encryption/group membership and firmware behavior remain simplified, not simulated.

The diffraction approximation uses `v = -clearance * sqrt(2 / (lambda*d1*d2/d))`; for v > -0.78, `J = 6.9 + 20 log10(sqrt((v-0.1)^2+1)+v-0.1)`, otherwise zero. It takes the maximum v across sampled interior terrain; endpoints are not blanket obstructions. This is a single dominant-edge approximation, not a full multiple-edge implementation. FSPL uses km and MHz with constant 32.44. Foliage segments use midpoint classification and true metric segment lengths. No analytical canopy height is baked into DEM data. Canopy height 15 m, per-meter loss, crowd/body loss and fade reserve are assumptions. `marginSensitivity` sweeps fade by +/-6 dB, expressly not a statistical confidence interval.

Graphs seed only the requested origin, preserve forwarding roles and require separate forward and reverse routes for targets. Crew mode requires every selected peer. Exact camp coordinates are evaluated independently from raster cells. Heat uses -1 unknown, 0 unavailable, 0.5 marginal, 1 likely, with every cell in area denominators. Marginal means 0–6 dB after explicit fade reserve; likely means >=6 dB, an engineering category rather than delivery probability. Synthetic community ghosts are no longer injected as observed infrastructure.

Optimizer maximizes weighted bidirectional mesh targets using the same graph/physical engine; baseline nodes are fixed. Added candidates obey explicit allowed/excluded flags and alternative heights share site IDs. Unknown access/power/mounting is always disclosed. Search is deterministic greedy with one swap pass, maximum 64 candidates and six added nodes. Baseline cannot worsen. Results include ranked layouts, gained targets, unavailable/unknown targets, bottleneck and removal contribution. This can miss beneficial multi-relay chains; labels say best found and not globally optimal. Exhaustive comparison is verified only on the included small one-add fixture; it is not proof of general optimality.
